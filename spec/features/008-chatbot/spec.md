# Specification: "Naranjito" Chatbot Componentization

## 1. Context & Objective
Refactor the static HTML/CSS design into a standalone Angular 18 component (`<app-chatbot>`) utilizing the Ionic framework.

## 2. Acceptance Criteria (Frontend Architecture)
* **Componentization:** The design must be transformed into an Angular standalone component (`chatbot.component.ts`, `chatbot.component.html`, `chatbot.component.scss`).
* **Native UI:** Replace generic HTML tags with semantic `ion-components` (`<ion-content>`, `<ion-footer>`, `<ion-input>`, etc.) to ensure mobile-first behavior.
* **Ephemeral Memory (Local State):** Implement reactivity using Angular Signals to manage the array of session messages.
* **Initial State:** The chat must load with the following initial system message: "¡Hola, aficionado! 🍊 Soy Naranjito, tu asistente de Inteligencia Artificial. Llevo desde el 82 calentando en la banda para un torneo como este. Pregúntame sobre alineaciones, estadísticas en tiempo real, goleadores o cualquier detalle de los partidos. ¡Ponte la camiseta y que ruede el balón!"
* **Sliding Window:** The controller must contain logic to slice the message array, retaining only the last 5 messages to protect backend request quotas.
* **Gemini API Integration:** Develop a `ChatService` that connects to the Gemini API (via Firebase AI Logic or directly), sending the conversation history and receiving AI-generated responses regarding World Cup 2026 data.

## 3. Implementation Plan
1. Generate the file structure for the component and the service.
2. Translate the static HTML into the Angular template, integrating structural directives (`@for`, `@if`) to render the Signals state.
3. Migrate and isolate the SCSS styles, ensuring WCAG 2.1 contrast and accessibility compliance.
4. Connect the user input with the mocked service and verify the rendering of the message flow.
