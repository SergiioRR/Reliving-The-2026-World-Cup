# CONSTITUTION: Mission, Vision & Branding ("DOMINIO ESPAÑOL")

## 1. Project Purpose & Academic Scope
- **Project Title:** El Mundial de mi Vida — 2026 World Cup Commemorative Web Application.
- **Academic Context:** 3rd-year Computer Engineering Portfolio Project at Universidad de Zaragoza (EINA).
- **Target Launch Date:** **August 19, 2026** (Non-negotiable milestone commemorating Spain's victory month).

## 2. Core Brand Identity ("DOMINIO ESPAÑOL")
- **Hero Branding:** The primary mobile interface MUST feature the typography and visual concept **"DOMINIO ESPAÑOL"** in the first level of reading (above the fold).
- **Emotional Narrative:** The application serves as a personal and collective celebration of Spain's tournament dominance, combining historical data, real-time match timelines, and interactive AI exploration.

## 3. Product Principles & Mobile-First Philosophy
- **Native Mobile Experience:** Prioritize native mobile UX patterns using Angular 18+ and Ionic Framework Standalone UI components.
- **Instant Access ($O(1)$ Reads):** Match data, lineups, substitutions, and statistics must load instantaneously from denormalized Google Cloud Firestore documents without client-side relational joins.
- **Universal Accessibility:** Strictly adhere to **WCAG 2.1 AA/AAA** standards, ensuring high contrast, keyboard operability, and adaptive motion for all users.
